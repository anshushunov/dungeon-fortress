# Документация проекта

- `product/` — питч, видение, roadmap, референсы.
- `design/` — механики: контракт Prototype 1, спеки срезов, HUD, индикация сторон.
- `engineering/` — настройка окружения, запуск headless-симуляции и graybox.
- `decisions/` — ADR: движок, стек, границы слоёв, ключевые игровые контракты.
- `art/` — происхождение ассетов и пайплайн анимации.
- `playtests/` — записи и данные плейтестов.
- `OPEN_QUESTIONS.md` — вопросы без решения.

Главная идея игры — [`product/PITCH.md`](product/PITCH.md). Что сделано и что
дальше — [`product/ROADMAP.md`](product/ROADMAP.md).

Контракт текущего прототипа — `design/PROTOTYPE_01_PREPARE_FOR_RAID.md`. Два
теста симуляции читают его напрямую и сверяют числа, поэтому таблицу тюнинга в
нём менять вместе с `PrototypeTuning.cs`.

## Что где фиксировать

| Содержание | Место |
|---|---|
| Идея и core gameplay | `product/PITCH.md` |
| Что сделано и очередь | `product/ROADMAP.md` |
| Как работает механика | короткий раздел в `design/` |
| Смена движка, стека, границы слоёв | `decisions/` |
| Задача с наблюдаемым результатом | GitHub Issue или описание PR |
