# ADR 0003: Стек первых прототипов

- Статус: Accepted
- Дата: 2026-07-26
- Ответственные: владелец проекта и агенты разработки

## Контекст

Проекту важнее быстро находить интересные механики, чем заранее максимизировать
производительность. При этом код должны автономно изменять и проверять агенты, а
ядро симуляции должно допускать детерминированные headless-сценарии.

Полное сравнение хранится в
`docs/engineering/STACK_EVALUATION.md`.

## Рассмотренные варианты

### Godot .NET + C#

Лёгкий специализированный 2D-контур, CLI/headless и свободная лицензия.
Симуляцию можно вынести в обычную .NET-библиотеку.

### Unity + C#

Более зрелые Test Framework, ECS и MCP-интеграции, но более тяжёлый цикл работы с
редактором и больше инфраструктуры проекта.

### Bevy + Rust

Сильная data-oriented модель, однако на текущей стадии стоимость итерации и
инструментов выше ожидаемой пользы.

## Решение

- Godot 4.7.1 .NET edition как движок представления.
- C# и .NET 8 как основной стек.
- 2D сверху для первого прототипа.
- Чистая библиотека симуляции, не зависящая от Godot.
- `dotnet test` для доменных правил и Godot headless для интеграционных
  smoke-тестов.
- Project-owned domain MCP остаётся независимым от движка.
- Для editor automation принят dev-only Ivan-MCP с осознанным риском по
  [ADR 0004](0004-dev-only-ivan-mcp.md).

## Последствия

- Основная часть разработки и проверки не требует открытого редактора.
- Представление можно позже сменить на изометрическое без замены доменной модели.
- Нельзя хранить каноническое состояние игры в дереве сцены.
- Godot MCP остаётся закреплённым dev-only инструментом; обновление pin или
  security-модели требует повторного spike.
- Переход на Unity остаётся дешёвым только до начала производства контента,
  поэтому spike проводится до первого большого вертикального среза.

## Проверка решения

Spike из `docs/engineering/STACK_EVALUATION.md` выполнен в Issue #3 и #4:
детерминированная симуляция, Godot host и domain MCP прошли проверки. Ограничения
editor automation и принятое для прототипа исключение зафиксированы в ADR 0004.
